### 要补的三个缺口
1. 泛型组件 `NeonWorldUi<V: NuiFlowVars>`（vars 字段即变量字段）+ trait 加 `apply_changes`（UI→Bevy 回写方向）。
2. world UI + screen UI 合并为一张带深度的统一纹理导出（screen UI 置顶，world UI 之间正确遮挡；
   与 3D 几何互遮挡依赖宿主用 Neon depth 合成）。
3. 交互闭环：Bevy 固定系统采样 ID target → 语义事件 → 变量变化 → 权威回流 `apply_changes` 回写组件字段。

### 用户设计要点（需求原文提炼）
- 场景 1000 个 world UI，每个来自不同 world position，绑一个 `.nui` + 一组变量。
- `NeonWorldUi` 是泛型组件，绑定变量是实现了 `NuiFlowVars` 的结构体，其字段即变量字段。
- 不在摄像机的 UI 完全剔除。
- world UI 与 screen UI 不能再分两块，最终渲染一张有正确深度关系的纹理给外部引擎。
- 鼠标交互走交互层纹理（ID 拾取），点击改变量后自动回写 Bevy。
