## 修复：wgpu-runtime 强制 DX12（external host interop）
- 报错 `DX12 HAL adapter is unavailable`：wgpu `request_adapter` 默认 `Backends::all()` 会选非 DX12 backend（如 Vulkan），导致 `adapter.as_hal::<Dx12>()` 返回 None。
- 修复：`neon-wgpu-runtime/src/lib.rs` `initialize` 里 `InstanceDescriptor` 加 `backends: wgpu::Backends::DX12`。
- Windows cargo 编译锁（`.cargo-build-lock` 拒绝访问）：需 `dangerouslyDisableSandbox` + 停残留进程 + PowerShell 删锁文件。
